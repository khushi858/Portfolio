## Overview
This is the personal **portfolio website of Khushi Upadhyay**, showcasing projects, skills, and experience. The portfolio is designed to be **frontend-focused** with modern design, animations, and responsiveness across devices. It also includes backend integration for form submissions and other dynamic features.

---

## Features
- Responsive design for desktop, tablet, and mobile
- Interactive hero section with animations
- Project showcase with descriptions and links
- Skills section highlighting frontend and backend technologies
- Contact form with email integration
- Smooth scrolling and interactive navigation

---

## Technologies Used

### Frontend:
- HTML5, CSS3
- Tailwind CSS
- JavaScript (ES6+)
- React.js
- Figma (UI/UX design)

### Backend:
- Node.js / Express.js (for contact form handling)
- Python / Django (optional API integration)
- SQL (for database if needed)

### Tools & Libraries:
- Vite (React build & dev server)
- Framer Motion (animations)
- Git & GitHub (version control)
